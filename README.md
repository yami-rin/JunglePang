# Jungle Pang

昔のLINEトークルーム内版を参考にした、40秒の左右タップゲームです。独自の動物・背景・音を使用する非公式の再現版です。

## あそぶ

[公開版をスマホ・PCのブラウザであそぶ](https://yami-rin.github.io/JunglePang/)。インストール・ログインは不要です。スマホは縦画面で、下の大きな左右ボタンをタップしてください。

### ローカルで起動する場合

Windowsは `START-JUNGLE-PANG.cmd` を起動し、表示された **http://localhost:5177/** をブラウザで開いてください。Node.js 22.12以降が必要です。初回だけ依存を取得してビルドします。

塔のいちばん下と同じ動物をタップすると1個進みます。サル・トラ・ゾウ・カエル・カバ・ヒヨコから、色と形が区別しやすい2種類を毎回抽選します。そのゲーム中の左右は変わりません。PCは **← / →** または **A / D** でも遊べます。押しっぱなしは1入力です。

ミスでは650ms操作できなくなり、時間は進みます。40秒終了後に結果を表示し、自己ベストを端末内に保存します。右上からミュート・音量・BGMを設定できます。画面切替、設定を開く、タイトルへ戻る操作は中断扱いとなり、中断した得点は自己ベストに残りません。

右上のトロフィー、タイトル、結果画面から全国ランキングを見られます。40秒完走すると、結果画面でニックネームを入力して「全国に登録」できます。端末ごとの最高記録だけを公開し、同点は同じ順位です。個人情報を名前に含めないでください。通信や準備が間に合わなかったゲーム、中断、検証モードの記録は全国に登録せず、端末内の遊びは続けられます。

ローカル版をスマホで確認する場合はPCと同じネットワークに接続し、PCのLANアドレスと `:5177` を開いてください。ファイアウォールなどで接続できない場合があります。サーバーはLANから接続できるよう `0.0.0.0` で待ち受けます。PC内だけで使う場合は `HOST=127.0.0.1` を指定してください。

## 開発・検証

```sh
npm ci
npm run dev
npm run test
npm run build
npx playwright install chromium
npm run test:e2e
```

`npm run start` はビルド済みの `dist/` を、外部依存のないNodeサーバーで配信します。終了はCtrl+C。`dist/` を静的Webサーバーに配置しても遊べます。HTMLファイルの直接ダブルクリックには対応しません。

`npm run package` でWindows用のZIPを `release/` に作れます。ZIPにはビルド済みゲーム・ソース・起動スクリプト・検証資料を含みます。通常の起動には `node_modules/` は不要です。描画に実行時ライブラリは使わず、SVGとブラウザ標準のアニメーションだけを使用します。

既存のChromiumを使う場合は `PLAYWRIGHT_CHROMIUM_EXECUTABLE` に実行ファイルを指定できます。E2Eは通常の40秒ラウンド、左右入力、15入力/秒、20回再試行、保存、画面サイズを確認します。`?debug=1` は固定シード・ログ・終了操作を提供する検証用モードです。通常のプレイに診断ボタンは表示されません。

## 公開版を更新する

正本は [yami-rin/JunglePang](https://github.com/yami-rin/JunglePang)。`main` にゲーム・検証コードの変更をpushすると、[GitHub Actions](.github/workflows/pages.yml) が単体試験とビルドを実行し、成功した `dist/` だけをGitHub Pagesへ公開します。手動更新はActionsの「Publish Jungle Pang」から「Run workflow」を実行してください。

公開版のブラウザ試験は `PANG_E2E_URL=https://yami-rin.github.io/JunglePang/` を指定して `npm run test:e2e` で実行できます。公開URLとローカルURLは別オリジンなので、自己ベストや音量はそれぞれ保存されます。公開停止・復旧手順は [公開運用](docs/publishing.md) にあります。

ランキングAPIはCloudflare Workers + D1です。`npm run deploy:api` は認証済みCloudflareアカウントから、このゲーム専用のAPI・DBへ反映します。APIはGitHub Actionsから自動配信せず、秘密情報をソースやActionsへ追加していません。API側の更新がある場合は先にAPIを反映・確認してください。`src/ranking-config.json` に公開APIのURLを記載しています。

ランキングの共有登録を実際に検証するE2Eは `PANG_RANKING_LIVE=1` で明示的に有効化します。テスト用の参加IDは `test-results/ranking-smoke-player.json` に保存され、確認後にその参加者のデータだけを削除する必要があります。通常のE2Eは公開ランキングへ記録を送信しません。

## 原作との差分・現時点の検証範囲

原作の採点式・正確な硬直・コンボ条件・描画テンポは未確認です。現行は **正解10点、10コンボごとに加点が5点増加（加点最大30点）、ミス650ms、先読み6段** の近似ルールです。`src/rules.json` で調整でき、変更後は再ビルドが必要です。

スマホ実機の両手入力・音の聴感・2フレーム以内の視覚反応・原作経験者による操作感の評価は未実施です。ブラウザのモバイル模擬試験は実機確認の代わりにはしていません。原作と一致する完成版とは公称しません。
