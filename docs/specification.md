## 入力契約

Pointer Eventsの新規 `pointerdown` を1回だけ受ける。互換 `click(detail > 0)` は採点しない。押し続けた同一ポインターは重複採点しない。`pointerup/cancel` で解放する。異なる指は個別に受け付け、同時入力はブラウザから届く順に判定する。ボタン外からスライドして入るだけでは入力にならない。

左右/A/Dの新規keydownを受け、OSリピートは捨てる。ボタンにフォーカスしたEnter/Spaceも新規keydownを1回受ける。支援技術による `click(detail = 0)` はボタン活性化として受け付ける。設定ダイアログ操作中は採点しない。

高頻度タップでエフェクトが増え続けないよう描画オブジェクトを固定プールにする。得点と駒の列は描画状態から独立して進む。入力ログはラウンドあたり4096件に制限し、シード・入力・単調時刻から同じ結果を再生できる。

## 素材台帳

| ファイル・領域 | 制作と使用条件 |
|---|---|
| `public/art/monkey.svg` | 本プロジェクトで制作した独自のサル。原作画像の複製を使用しない |
| `public/art/tiger.svg` | 本プロジェクトで制作した独自のトラ |
| `public/art/jungle.svg` | 独自のSVG背景、樹木・葉・光 |
| `public/art/favicon.svg` | 独自の字形アイコン |
| UIアイコン・文字 | プロジェクト内SVGとシステムフォント。外部フォントの配信なし |
| `src/audio.ts` | Web Audioによる独自の合成音。既存の曲・録音・音源ファイルなし |
| Phaser | 3.90.0、MIT。`node_modules/phaser/LICENSE.md`参照。配布ZIPにライセンスを同梱 |
| EventEmitter3 | Phaserの実行時依存、MIT。配布ZIPにライセンスを同梱 |
| Vite / Vitest / TypeScript / Playwright | 開発・検証用依存。バージョンはpackage.jsonとlockfileで固定 |

原作とLINEの公式復活版ではないことをタイトル画面に表示する。素材の権利処理に関する法律判断は実施していない。現段階ではローカル検証用。名称・表示を含む公開方針は、公開する場合に別途決める。
