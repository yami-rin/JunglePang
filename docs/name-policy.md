# ランキングの名前フィルター

ブラウザとAPIは `src/ng-names.json` を共有する。ゲームの公開ニックネーム向けに選んだ辞書で、外部リストの一括取り込みは行っていない。0.3.2の辞書は265項目、一般語の例外は20項目。

| 分類 | 項目数 | 照合 |
| --- | ---: | --- |
| 日本語の性的な卑語・成人向け表現 | 66 | 部分一致 |
| 日本語の排泄語 | 15 | 部分一致 |
| 日本語の罵倒・脅迫 | 24 | 部分一致 |
| 日本語の差別語 | 17 | 部分一致 |
| 日本語の薬物表現 | 9 | 部分一致 |
| 短く曖昧な罵倒・成人向け表現 | 14 | 名前全体の一致 |
| 英語の卑語・差別語・薬物表現と代表的な数字置換 | 86 | 単語一致 |
| ローマ字表記 | 34 | 単語一致 |

## 照合と表示

比較するときだけ文字幅・英字大小・かなの大小を統一し、カタカナをひらがなに変換する。区切り記号・空白・制御文字・長音を除いて表記揺れを照合する。濁点は保持する。英語とローマ字は隣接するラテン文字がある場合を単語の途中とみなし、`Yoshito`・`Assassin`・`Hancock` などを巻き込まない。空白や句読点は単語境界とするが、ゼロ幅文字だけでは境界にしない。英字の後ろの数字や日本語の接尾語はNG語を隠す方法にならない。

例外は、その一般語の中にある一致だけを無効にする。`パチンコうんこ` は `パチンコ***` になり、パチンコを含む名前全体が判定を免れることはない。`ばか` などの短い語は名前全体が一致した場合だけNGとし、`ばかり` や `あほうどり` を保つ。英語の一般語でもある `shine` など、曖昧なローマ字は採用しない。

新規のNG名は登録を拒否し、名前を直して同じラウンドを送信できる。既存名はNG語の文字だけを半角 `*` に置換する。

| 元の名前 | 表示 |
| --- | --- |
| おまんこ | お*** |
| うんこ太郎 | ***太郎 |
| う・ん・こさん | *・*・*さん |
| 田中 Fuck | 田中 **** |
| パチンコ王 | パチンコ王 |

元の文字位置と照合用の文字位置を別に持つ。濁点や結合アクセントは基底文字と一緒に置換する。NG語以外の文字幅・大小文字・絵文字・区切り記号・空白は保持する。NG語の長音も、辞書に含まれている場合は置換する。

APIは伏字済みの一覧に辞書版 `namePolicyVersion` を付ける。同じ版のブラウザは再処理しない。たとえば `くうんこそ → く***そ` を再照合して `くそ` と誤認し、残りの文字まで消すことを防ぐ。ローカル保存は元の名前を保持し、表示時に1回だけ処理する。

## 辞書の編集

1. 語を適切な分類へ追加し、`contains`・`word`・`exact` を選ぶ。普通の名前と共通する短い語を安易に部分一致へ追加しない。
2. 一般語が誤判定される場合は具体的な語を例外へ追加する。例外で名前全体を許可しない。
3. `tests/name-policy.test.ts` に実際の誤判定や回避表記を追加する。全辞書項目の検出、部分伏字、一般名、SQL経由の3カテゴリ、ブラウザ表示を検証する。
4. 辞書の `version` を増やし、APIとフロントを更新する。DBを書き換える必要はない。

辞書は意味や文脈を理解する仕組みではなく、全ての隠語・他言語・似た字形の偽装を網羅しない。一般語や人名と同じ表記になる語もある。報告を受けた場合は、その名前を例にして照合方式と例外を見直す。
